ANDOR Analog test build for Windows (64-bit)

1. Unzip this folder (right-click, Extract All).
2. Double-click Install.bat and allow it to make changes (VST3 plug-ins live in
   Program Files). If Windows SmartScreen warns: More info, then Run anyway (this
   build is not signed).
3. Restart your DAW and rescan plug-ins. Use the VST3 "ANDOR Analog" (Ableton Live,
   Cubase, Reaper, Studio One, Bitwig, FL Studio).
   The standalone app is in the Start menu: ANDOR Analog (choose your audio device in
   Options).

The 34 factory sounds appear in the preset list (Presets/Factory) after the first launch.

Installed to:
  VST3        C:\Program Files\Common Files\VST3\ANDOR Analog.vst3
  Standalone  C:\Program Files\ANDOR Analog\ANDOR Analog.exe

Uninstall: delete those two, the Start menu entry "ANDOR Analog", and (if you like)
Documents\ANDOR Analog.
